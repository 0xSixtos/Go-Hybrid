hyb (build driver). 194 workspace tests green (`cargo test --workspace`),

(bug-1/bug-2 and the eleven Batch-I fixes).

**2. Structs, enums, pattern matching, functions, closures, basic generics.**
Pinned by target programs: structs + methods (03, 09, 18), option-match
lowering (07), generics `[k comparable, v any]` (07), closures incl.
HandlerFunc conversion with target-typed params (06), type aliases + assoc

option/match (the enum-shaped surface the ten programs use), not general
enums.** This is the one SPEC row delivered narrower than written; it is
logged, not hidden (PLAN Decision Log, batch B/D entries).

**3. Error handling per Spike 5 with postfix propagation.**
E3 `?` desugar (hyErrN temps, named-result reuse), E3b expression form,
E6 main exit contract (byte-for-byte §6.2), E11 handler contract, M2b
package-mode propagation, `return _, err` zero-fill. Every error path in
the ten programs exercises it (02's CLI error path verified on stderr +
exit 1).

**4. Calling Hybrid from Go; a defined set of Go packages from Hybrid;
Rust crates from Hybrid.**

  committed consumer `main.go` runs with `go run` and NO Hybrid toolchain

- Go packages from Hybrid: net/http (06), sync/atomic (17), sync (18),

  table (M5's honest scope; not "any Go package").
- Rust from Hybrid: sha3 0.10.8, serde_json 1.0.140, regex 1.11.1 through
  the live bridge (hyrt staticlib + hybridge trampolines + per-crate Go
  bindings), pinned in hyrt.

**5. Safe-mode checking for what Spike 6 shows is implementable.**

## What this gate does NOT claim (honest scope)

- **General enums + exhaustive match**: option/match only (above).
- **Multi-package Hybrid→Hybrid imports** (M3's third form) — post-MVP.
- **A real type checker**: receiver/shape knowledge lives in the curated
  tables (shapes.rs + the Batch-I maps); the keys ARE the future checker's
  descriptor types, but the checker itself is post-MVP.
- **Rustdoc-JSON descriptor automation**: bindings are hand-shaped per
  pinned crate (M6's documented scope).
- **Sanitizers / fuzzing / Kani**: fleet-scale items (SPEC routes them to
  the Actions fleet "at each milestone and review gate, not on every
  commit"); not yet exercised for the MVP — the next fleet dispatch should
  run them against this SHA before any release.
- **Worker-tier re-measurement of the bench**: sandbox numbers only (G2
  follow-up #1).
- **Broad stdlib / full net/http surface** beyond the pinned programs'
  needs (stretch rows, untouched by design).
